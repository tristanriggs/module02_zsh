## Commands Practiced

| Command        | What it does                            |
|----------------|-----------------------------------------|
| pwd            | Prints the current working directory    |
| ls             | Lists visible files and folders         |
| ls -la         | Lists all files including hidden ones   |
| cd..           | go up one level                         |
| cd ~/          | Jump to course folder                   |
| tree -L 2      | Visualise the entire folder structure   | 
| cd             | Return to lab folder                    | 
| head -1        | Reads first line                        |
| cp             | Copy the file                           |
| mv             | Rename the file                         | 
| code .         | Opens VS code                           |
| rm             | Erases the whole file for good          |
